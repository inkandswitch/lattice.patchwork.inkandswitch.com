# patternwitch

a pixel painter: a grid of palette colours, 2 to 6 of them. a copy of
patternwitch from [patchwork-pkg-base](https://github.com/inkandswitch/patchwork-pkg-base),
to make lattice's own. lattice's frame registers it (packages/lattice/index.js)
under the same ids as pkg-base's, so it stands in for that one, and the +
menu in a project makes one.
